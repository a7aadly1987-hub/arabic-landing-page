# برومبت: صفحة سينمائية بسماء ونجوم (قالب «سُهيل»)

انسخ النص التالي إلى Claude وغيّر ما بين الأقواس `[ ]`.

```text
أنت مصمم ومطوّر واجهات محترف. أنشئ صفحة هبوط عربية (RTL) في ملف index.html واحد،
يحتوي الـ CSS والـ JavaScript بداخله، بدون مكتبات وبدون أي صور خارجية.

النشاط: [اسم النشاط] — [وصف في سطر، مثال: مخيم صحراوي لرصد النجوم]
العرض الرئيسي: [مثال: ليلة تخييم مع مرشد فلكي] بسعر [السعر]
بيانات التواصل: [هاتف / واتساب]

الطابع: سينمائي داكن. خلفية ليل كحلي، لون أساسي ذهبي دافئ، ولون ثانوي فيروزي.
خط العناوين El Messiri وخط النصوص Tajawal من Google Fonts.

القسم الرئيسي بارتفاع الشاشة، ومشهده مرسوم كله بالكود:
- نجوم على عنصر canvas تتلألأ، مع شهاب يمرّ كل بضع ثوانٍ.
- بقعتا شفق ملوّن بتمويه (blur) تتحركان ببطء.
- قمر مرسوم بتدرج CSS وله توهج.
- ثلاث طبقات كثبان SVG في الأسفل تتحرك بسرعات مختلفة مع التمرير (parallax)،
  وبينها خيمة صغيرة مضيئة.
- عنوان كبير بجزء ملوّن بتدرج، جملة فرعية، وزرّان.
- بطاقة زجاجية (backdrop-filter) فيها تفاصيل العرض والسعر وزر حجز،
  وتميل مع حركة الماوس بتأثير 3D مع لمعة تتبع المؤشر.

باقي الأقسام بالترتيب:
1. شريط أرقام زجاجي بعدّادات متحركة يتداخل مع نهاية القسم الرئيسي.
2. ثلاث بطاقات عروض، لكل بطاقة رسم SVG ليلي مختلف وقائمة مزايا وسعر وزر
   يختار العرض تلقائياً في نموذج الحجز.
3. قسم «كيف تسير التجربة»: خط زمني من أربع محطات، وبجانبه كوكبة SVG
   تُرسم خطوطها عند ظهورها (stroke-dashoffset).
4. أسئلة شائعة بنظام الأكورديون.
5. نموذج حجز (الاسم، الهاتف، اختيار العرض) مع تحقق من المدخلات ورسالة نجاح.
6. تذييل بروابط سريعة وأيقونات السوشيال والسنة الحالية تلقائياً.

معايير لازمة:
- متجاوب تماماً وبدون تمرير أفقي، مع قائمة همبرغر على الموبايل.
- ظهور العناصر عند التمرير عبر IntersectionObserver، ولا يختفي المحتوى إن تعطّل JavaScript.
- احترام prefers-reduced-motion: النجوم ثابتة، ولا بارالاكس ولا ميلان.
- أوقف حلقة الرسم عندما يخرج القسم الرئيسي من الشاشة أو يُخفى التبويب.
- HTML دلالي، حالات focus واضحة، aria-label حيث يلزم، وتباين ألوان كافٍ.
- وسوم title و description و Open Graph و favicon مضمّن كـ SVG.
- كل الألوان متغيرات CSS في :root، وتعليق قصير عند بداية كل قسم.

لا تعدني بنتائج أو أرقام غير مذكورة؛ أي رقم تفترضه اجعله سهل التعديل.
سلّم الملف كاملاً بدون اختصار.
```
