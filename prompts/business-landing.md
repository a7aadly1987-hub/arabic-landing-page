# برومبت: صفحة هبوط لأي نشاط (قالبا «نَسَق» و«ميزان»)

انسخ النص التالي إلى Claude وغيّر ما بين الأقواس `[ ]`. الخانة التي تتركها فارغة سيملؤها بمحتوى مناسب للمجال.

```text
أنت مصمم ومطوّر واجهات محترف. أنشئ صفحة هبوط عربية (RTL) في ملف index.html واحد،
يحتوي الـ CSS والـ JavaScript بداخله، ويعمل فور فتحه بدون مكتبات أو خطوات بناء
أو صور خارجية (استخدم SVG مضمّناً وأشكال CSS فقط).

النشاط: [الاسم] — [المجال، مثال: مكتب محاماة / استوديو تصميم / عيادة]
وصف مختصر: [سطران]
الخدمات (3 إلى 6): [...]
الجمهور المستهدف: [...]
بيانات التواصل: [هاتف / واتساب / إيميل / عنوان]
الألوان: [لونان، أو اتركها لتناسب المجال]
الطابع: [رسمي / عصري / فاخر / بسيط]

الأقسام بالترتيب:
1. شريط تنقل ثابت بشعار نصي وروابط وزر تواصل، يتحول لقائمة همبرغر على الموبايل.
2. قسم رئيسي بعنوان قوي وجملة فرعية وزرّين، وبجانبه رسم توضيحي مرسوم بالـ CSS.
3. نبذة مع أربعة أرقام بعدّاد متحرك.
4. الخدمات في بطاقات بأيقونات SVG.
5. لماذا نحن: أربع مزايا مرقّمة.
6. معرض أعمال أو قطاعات في شبكة بطاقات برسومات SVG.
7. ثلاث شهادات عملاء.
8. أسئلة شائعة بنظام الأكورديون.
9. نموذج تواصل (الاسم، إيميل أو هاتف، الرسالة) بتحقق من المدخلات ورسالة نجاح،
   وبجانبه بيانات التواصل وزر واتساب.
10. تذييل بروابط سريعة وأيقونات السوشيال والسنة الحالية تلقائياً.

معايير لازمة:
- لوحة ألوان كمتغيرات CSS في :root، مع وضع فاتح وداكن وزر تبديل يحفظ الاختيار.
- خط Tajawal من Google Fonts، مسافات واسعة، حواف دائرية وظلال ناعمة.
- ظهور العناصر عند التمرير عبر IntersectionObserver، ولا يختفي المحتوى إن تعطّل JavaScript.
- احترام prefers-reduced-motion، وتمرير سلس، وزر عودة للأعلى.
- متجاوب تماماً وبدون تمرير أفقي.
- HTML دلالي، تنقل كامل بلوحة المفاتيح، focus واضح، aria-label حيث يلزم.
- وسوم title و description و Open Graph و favicon مضمّن كـ SVG.
- تعليق قصير عند بداية كل قسم وعند مكان تعديل النصوص والألوان.

للمجالات المهنية (محاماة، طب، استشارات مالية): لا تكتب أي وعد بنتيجة أو نسبة نجاح.
سلّم الملف كاملاً بدون اختصار، ثم ثلاثة أسطر تشرح تعديل الألوان والنصوص وبيانات التواصل.
```
